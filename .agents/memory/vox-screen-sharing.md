---
name: Vox screen sharing expectation
description: Product intent and limits for Vox's screen-sharing feature.
---

Vox screen sharing is for asking questions about anything visible on the phone, similar to Gemini Live's screen awareness. It is not a game-specific assistant or a feature that should tap through games.

**Why:** the user explicitly asked for screen understanding like Gemini Live after seeing the feature labeled and failing as “Game assist.”

**How to apply:** use general screen-vision analysis and non-game-specific wording. Be clear that frame-per-question capture is not continuous live video streaming.
